# 🤖 TechPulse AI-Support Bot

> 💡 Intelligent email assistant for automated customer support replies  
> Reads incoming emails → extracts order numbers → checks the database → generates polite, human-like responses.

---

## ✨ Features

- 📬 Connects to **Gmail API** and reads new customer emails  
- 🧠 Uses **LLM (Qwen-14B / Llama-3)** to understand intent and extract data  
- 🔍 Finds order information in **SQLite / MySQL**  
- 💬 Generates personalized replies in **German or English**  
- 🧾 Logs every processed message for auditing  
- ⏱️ Supports **Cron automation** (e.g. every 2 min)
